# STEP 6. Экспериментальная реконструкция raw → 531

Дата: 2026-09-28.

Это эксперимент. Он не объявляет, что raw ECG превращается в вектор, на котором обучена сеть.

## Objective

Проверить, можно ли из raw записи PTB-XL `00513` через ECGDeli 1.1 и описанную в статье агрегацию получить опубликованные 531 число. Оригинальный скрипт агрегации по-прежнему не найден. Неизвестные параметры не подставлялись.

## Dataset

PTB-XL 1.0.3, запись `00513`, оба файла:

- `records500/00000/00513_hr`: 12 отведений, 500 Гц, 5000 отсчётов, 10 с, gain `1000.0/mV`, baseline в поле gain равен 0, ADC zero равен 0, формат 16.
- `records100/00000/00513_lr`: 12 отведений, 100 Гц, 1000 отсчётов, 10 с, те же gain, baseline и ADC zero.

Имена в заголовке: `I, II, III, AVR, AVL, AVF, V1, V2, V3, V4, V5, V6`.

Опубликованная строка: PTB-XL+ 1.0.1, `ecg_id=513`, префикс `research/ecgdeli_reproduction/data/ptbxl_plus/ecgdeli_features_prefix.csv`. В ней 531 колонка схемы плюс `ecg_id`.

Какой файл использовали авторы: `UNKNOWN`.

## ECGDeli

Версия 1.1, commit `3c13b1b2ff55152360f3cee992c1d1d66099aa14`, checkout `/tmp/ECGdeli`, вне дерева продукта.

Проверены MATLAB, Octave и MATLAB Runtime. Ни одного нет. ECGDeli не стартовал. NeuroKit2, BioSPPy, другой делинеатор и перенос функций ECGDeli на Python не использовались. Опубликованные fiducial points в признаки не пересчитывались.

Каталог `experiments/raw_to_531/ecgdeli_output/00513/` содержит только `RUN.txt`. Схема в `ecgdeli_output_schema_00513.json` снята с исходников и помечена `observed_on_this_record: false`.

Заявленные выходы, которых на записи нет:

- таблица точек по отведению и синхронная таблица;
- интервалы по комплексу: P, QRS, T, PQ, PR, QT, RR;
- синхронные интервалы и Framingham QTc на каждом комплексе;
- амплитуды P, Q, R, S, T;
- морфология P с кодами −3, −2, −1, 1, 2, 3.

Эти функции не объявляют `ST_Elev`, `HA__Global`, lead-wise `QT_IntCorr`, медиану, IQR, count и CSV из 531 колонки.

## Preprocessing variants

Вариант A — сырой сигнал 500 Гц. Вариант B — сырой сигнал 100 Гц. Оба не исполнялись.

Фильтр, isoline, notch, перевод ADC в mV и порядок каналов на входе ECGDeli: `UNKNOWN` в обоих вариантах. Отдельные варианты C не вводились: для них нет указанного авторами набора параметров, а подбирать фильтр по строке 513 запрещено.

Перестановка отведений не делалась. Соответствие «канал ECGDeli → колонка CSV» для прогона авторов не заполнено.

## Aggregation

`experiments/raw_to_531/reconstruct_aggregation.py` реализует только то, что говорит статья: медиана, IQR как процентиль 75 минус процентиль 25, число конечных комплексов. Метод процентиля `linear` — параметр этой программы, не подтверждённый метод PTB-XL+.

Программа без таблицы комплексов завершилась кодом 2 и не прочитала опубликованный CSV. На запись 00513 агрегация не применялась.

## Feature-by-feature results

Сравнение всех 531 колонок со строкой 513 лежит в `experiments/raw_to_531/comparison_00513.csv`. Восстановленное значение пусто у каждой колонки. Абсолютная и относительная ошибки не заполнены. Это отсутствие пары, а не нулевая ошибка.

Пороги на будущее: exact при абсолютной разнице не больше `1e-6`, close при разнице не больше `1e-4`. Для count и морфологии запланировано только точное равенство. Пороги ни к одной колонке не применялись, потому что второго числа нет.

## Cross-record validation

Записи `00514`, `00515`, `00516` и `00517` не открывались. Условие шага — сначала работающий pipeline на `00513`. Его нет. `comparison_summary.csv` помечает их `NOT_RUN`.

## Neural-network sensitivity

`network_sensitivity_00513.json` не создавался. В восстановленном векторе нет 531 числа, поэтому сеть не вызывалась. Веса, нормализация и ансамбль не менялись. Production API не получал этот вектор.

## Unknown parameters

- частота и файл, которые открывали авторы;
- фильтр, notch, isoline, baseline;
- применялся ли перевод `(sample - baseline) / gain`;
- порядок каналов на входе ECGDeli;
- алгоритм квантиля;
- какое определение Global попало в CSV: max по отведениям или вторая крайняя граница;
- lead-wise `QT_IntCorr`;
- процедура `ST_Elev`;
- процедура `HA__Global`;
- как медиана считается для целых кодов морфологии, когда появятся комплексы.

## Limitations

Без MATLAB-запуска ECGDeli 1.1 нет таблицы комплексов. Агрегатор не имеет входа. 432 колонки помечены `MISSING`: для них ряд по комплексу в публичном ECGDeli описан, но не получен. 99 колонок помечены `NOT_REPRODUCIBLE`: публичный код не задаёт один однозначный ряд, и число не изобреталось.

Четыре обычных числа проверили только арифметику медианы и IQR. К кардиограмме они не относятся.

## Conclusion

Численного воспроизведения нет: 0 из 531. Статус `EXACT_REPRODUCTION_NOT_ESTABLISHED`. `RAW_TO_531_STATUS` остаётся `NOT_PROVEN`. Сырой ECG подавать в существующую сеть нельзя: вектора признаков нет.

Главное препятствие сейчас двойное. Прогон ECGDeli не стартовал, потому что нет MATLAB. Даже после запуска часть колонок останется без однозначного определения: Global, lead-wise QT correction, ST elevation и электрическая ось.
