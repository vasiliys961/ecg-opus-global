# Шаг 12. P_Morph и граница воспроизводимости

Запись только `00513`. `RAW_TO_531_STATUS` остаётся `NOT_PROVEN`. Сеть не вызывалась. Код ECGDeli не изменялся. Production extractor не писался.

## Среда

На машине нет `matlab`, `octave`, MATLAB Runtime и `docker`. В `/Applications` этих программ нет. Homebrew знает формулу Octave 11.3.0, пакет не установлен.

Ставить Octave, чтобы исполнить неизменённый `Get_P_Morphology.m` версии `3c13b1b2`, недостаточно. Функция вызывает `designfilt('lowpassfir', ..., 'SampleRate', 1000)`. Это функция MATLAB Signal Processing Toolbox. В GNU Octave её нет. Кроме того, в ветке M-формы v1.1 аргументы `findpeaks` перепутаны: `'MinPeakProminence'` получает строку `'MinPeakDistance'`. Этот вызов поправлен только на более позднем commit. Подгонять исходник под Octave значило бы выйти из v1.1.

Поэтому 36 колонок `P_Morph` не посчитаны. Это отсутствие среды исполнения, а не отсутствие FPT: функция принимает сигнал, частоту и cell-таблицу точек. Опубликованные `.atr` такой таблицей являются. Промежуточный артефакт морфологии в архиве не требуется и в архиве его нет.

Файл сравнения: `experiments/raw_to_531/pmorph_00513_final.csv`. У всех 36 строк `status = NOT_EXECUTED`.

## Что функция ждёт

`[PMorph, Peaks] = Get_P_Morphology(signal, samplerate, FPT)`.

Сигнал — матрица, отведение в столбце. Пример передаёт нефильтрованный `ecg`. Внутри: baseline 0,3 с с overlap 0,3, изолиния, вырезание QRST, FIR lowpass 15 Гц с жёстким `SampleRate` 1000. Коды по комплексам и отведениям: −3, −2, −1, 1, 2, 3, и 0, если форма не определилась. Единицы кода — целые. Полярность входит в знак кода. NaN в комментарии допускаются. Порядок отведений — порядок столбцов поданной матрицы, не порядок колонок CSV.

## Граница

Публичный ECGDeli 1.1 и опубликованные точки записи 00513 восстанавливают интервальную часть таблицы. Per-lead `QT_IntCorr` — свёртка уже существующих lead-wise рядов, не отдельная неизвестная функция, и порог `1e-6` она не проходит. Амплитуды читают сэмпл в пике; какой сигнал подавали авторы, материалы не фиксируют, а сырые милливольты дают единицы точных value/IQR. `P_Morph` в дереве есть и на этой машине не запускается. `ST_Elev` и `HA__Global` в дереве нет.

Полный вектор 531 из публичных материалов не восстановлен. Дальнейший перебор фильтров и поиск `ST_Elev` / `HA__Global` в этот аудит не входит.
