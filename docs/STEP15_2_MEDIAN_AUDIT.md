## 3. Fiducials

`fiducial_points/ecgdeli/`.

Файлы `{id}_points_lead_{lead}.atr` и `{id}_points_global.atr`.
Id с файлами: 3691. Полный набор из 13 файлов ненулевого размера: **2991**.

Одновременно полная пара 12SL и все 13 fiducial-файлов: **1996** id.
Первые десять: 2000, 2001, 2002, 2003, 2004, 2005, 2006, 2007, 2008, 2009.
Пример пути:

```text
.../median_beats/12sl/02000/02000_medians.hea
.../median_beats/12sl/02000/02000_medians.dat
.../fiducial_points/ecgdeli/02000/02000_points_global.atr
.../fiducial_points/ecgdeli/02000/02000_points_lead_I.atr
```

Имя файла совпадает по числу id. Совпадение координатной системы по содержимому не проверено: `.atr` в этом запуске не прочитан. Для уже разобранной записи 00513 того же издателя точки доходят до отсчёта 5000 при 500 Гц, то есть до конца 10 секунд. В median beat таких позиций нет: там 600 отсчётов. Поэтому fiducial sample number нельзя подставлять как индекс median beat. Запись 00513 в этот пересекающийся набор не входит: на Drive у неё есть median-пара и нет fiducials.

У 16047, 1000, 5000 и 10000 полного набора fiducials нет.

## 4. Что из 531 можно получить

Таблица: `docs/step15_2_feature_coverage.csv`.
Сводка: `docs/step15_2_summary.json`.

| Статус | Колонок | Смысл |
| --- | ---: | --- |
| DIRECT | 0 | Ни одна колонка не читается из median beat как готовый признак |
| DERIVABLE | 0 | В этом запуске ни одно число не посчитано |
| REQUIRES_FIDUCIALS | 240 | Интервалы, RR и Framingham QT. Формула есть в `ExtractIntervalFeaturesFromFPT`. Вход — точки, не median |
| REQUIRES_RAW_10SEC | 180 | P/Q/R/S/T амплитуды. Индекс точки относится к 10-секундной записи |
| UNKNOWN | 111 | `P_Morph` 36, `QT_IntCorr` 36, `ST_Elev` 36, `HA__Global` 3 |

240 интервальных колонок — это PQ, PR, QRS, QT, длительности P и T, RR и Framingham, включая value, IQR и count. Их можно считать из fiducials, когда файл открывается. Median beat для них не нужен и их не заменяет: в одном усреднённом комплексе нет ряда из многих RR.

Амплитуды из median не считались. Подстановка милливольт median в чужие индексы была бы другой величиной, не официальной колонкой. Даже на сыром сигнале официальная амплитуда раньше не была доказана: предобработка матрицы неизвестна.

Отдельно:

| Семейство | Колонок | Почему нет официального значения |
| --- | ---: | --- |
| QT_IntCorr | 36 | Фрамингем на QT отведения и дополненном RR известен, порог 1e-6 не пройден |
| ST_Elev | 36 | В ECGDeli 1.1 функции нет. Точка L не является амплитудой ST |
| HA__Global | 3 | Функции оси в ECGDeli 1.1 нет |

`P_Morph` в `.atr` кодом не записан. `Get_P_Morphology` не запускался.

Полный вектор 531 из median и fiducials не собран. Ансамбль MLP / 1D CNN / ResNet1D не вызывался.

Прежние 238 точных ячеек относятся к forensic-сверке записи 00513 с опубликованной строкой. Здесь этой строки нет, и fiducials 00513 на Drive нет. Эта цифра на текущие файлы не переносится.
