# STEP 7. Реконструкция 531 признаков из опубликованных fiducial points

Дата: 2026-09-28.

Это эксперимент по опубликованным точкам PTB-XL+, не запуск ECGDeli и не доказательство полного raw→531.

## Source

PTB-XL+ 1.0.1, DOI 10.13026/nqsf-pc74. Каталог `fiducial_points/ecgdeli/00000/`. Описание источника: `experiments/raw_to_531/fiducials/SOURCE.md`.

Формулы интервалов взяты из ECGDeli 1.1, commit `3c13b1b2ff55152360f3cee992c1d1d66099aa14`, функция `ExtractIntervalFeaturesFromFPT`. Они не подменялись примерами «конец P минус начало P» для PQ и «конец S минус начало Q» для QRS.

Подтверждённые разности, затем умножение на 2:

| Колонка | Конец | Начало |
| --- | --- | --- |
| P duration | p-wave offset | p-wave onset |
| QRS duration | QRS offset | QRS onset |
| T duration | t-wave offset | t-wave onset |
| PQ | QRS onset | p-wave onset |
| PR | R peak | p-wave onset |
| QT | t-wave offset | QRS onset |

Global-интервал — вторая самая поздняя конечная граница минус вторая самая ранняя начальная, по 12 отведениям одного комплекса. Слово max из словаря для этого не использовалось.

## Fiducial artifact

13 файлов `.atr` записи `00513`. В каждом есть пометка `## time resolution: 500`. Координата — номер отсчёта. Сдвиг «нулевой или первый отсчёт» на разности не влияет; для амплитуды он был бы существенен, поэтому амплитуда по сырому сигналу не считалась.

На каждом отведении и в global-файле по 12 комплексов и по 12 полей: границы и пики P, QRS, T, а также `L point (for STEMI)`. Исходные номера сохранены в `fiducials_00513.json`.

## Record 00513

12 комплексов. Все перечисленные поля присутствуют на всех 12 отведениях. Кода морфологии, амплитуды в мВ и параметров гауссовой аппроксимации в файлах нет.

## Directly reconstructable features

По отведениям восстановлены `PQ_Int`, `PR_Int`, `QRS_Dur`, `QT_Int`, `P_DurFull`, `T_DurFull`. Global-версии этих интервалов, плюс `P_Dur` и `T_Dur`, восстановлены правилом второй крайней границы. `RR_Mean_Global` взят из последовательных R пиков global-файла. `QT_IntFramingham_Global` посчитан по комплексам из синхронного QT и этого RR, затем агрегирован.

Агрегация: медиана, IQR как линейный процентиль 75 минус процентиль 25, число конечных комплексов. Метод процентиля — параметр программы. На тех рядах, где значение совпало точно, IQR тоже совпал точно.

## Non-reconstructable features

291 колонка не имеет входа в этих файлах:

- `P_Amp`, `Q_Amp`, `R_Amp`, `S_Amp`, `T_Amp`: функция берёт значение переданной матрицы сигнала. Фильтр и baseline этой матрицы неизвестны. Сырой отсчёт вместо неё не подставлялся.
- `P_Morph`: в файлах нет кодов −3…3. `Get_P_Morphology` заново не писался.
- `QT_IntCorr`: в исходнике Framingham есть только у синхронного QT, не у каждого отведения.
- `ST_Elev`: есть точка L с подписью STEMI и нет параметров гауссовых кривых. Приближённая аппроксимация не строилась.
- `HA__Global`: входа `elHA` нет, функции оси в ECGDeli 1.1 нет.

## Aggregation

Ряды комплексов: `beat_features_00513.csv`. Сводки: `aggregated_features_00513.csv`.

## QT correction

Оба варианта посчитаны. Победитель не выбирался. В таблицу сравнения попал первый, потому что так устроена функция: коррекция на комплексе, и только потом сводка по комплексам.

| Вариант | value | IQR | count |
| --- | ---: | ---: | ---: |
| 1. Коррекция, затем медиана | 518.866 | 63.651 | 12 |
| 2. Медиана QT и RR, затем коррекция | 520.560 | — | — |
| Опубликовано | 522.01 | 55.535 | 11 |

## ST_Elev

Точка L опубликована. Амплитуда ST и параметры Gaussian fit не опубликованы. Статус: `NOT_REPRODUCIBLE`.

## HA

Электрическая ось из этих точек не вычисляется. Статус: `NOT_REPRODUCIBLE`. Опубликованное значение строки 513 по-прежнему 2, IQR 0, count 1. Оно не подставлялось как результат расчёта.

## Global features

`PQ_Int_Global`, `PR_Int_Global`, `QRS_Dur_Global`, `QT_Int_Global`, `P_Dur_Global` и `T_Dur_Global` совпали с опубликованной строкой точно, включая IQR и count. Правило второй крайней границы для этой записи воспроизвело Global. Max по отведениям для них не требовался.

`RR_Mean_Global` и `QT_IntFramingham_Global` не совпали. См. ниже.

## Numerical comparison

Файл `comparison_fiducials_00513.csv`. Пороги: exact при абсолютной разнице не больше `1e-6`, close не больше `1e-4`. Для count любое ненулевое отличие — `DIFFERENT`.

| | |
| --- | ---: |
| total | 531 |
| exact | 210 |
| close | 0 |
| different | 30 |
| missing | 0 |
| not_reproducible | 291 |
| coverage | 240/531 = 45.2% |
| MAE по 240 парам | 1.924 |
| median absolute error | 0 |
| max absolute error | 37 |

MAE не равен нулю и не описывает невосстановленные колонки. Медиана ошибки равна нулю, потому что 210 из 240 пар совпали точно.

30 отличий:

- `aVF` и `aVL` у `PQ_Int`, `PR_Int`, `QRS_Dur`, `QT_Int`, `P_DurFull`, `T_DurFull`: значение и IQR стоят крест-накрест. Файл `00513_points_lead_aVF.atr` даёт числа опубликованной колонки `aVL`, и наоборот. Имена файлов не менялись.
- `RR_Mean_Global`: восстановлено 860, IQR 28.5, count 12. Опубликовано 862, IQR 37, count 11.
- `QT_IntFramingham_Global`: восстановлено 518.866, IQR 63.651, count 12. Опубликовано 522.01, IQR 55.535, count 11.

После сравнения замечено, что 11 последовательных интервалов RR, без повтора последнего, дают ровно опубликованные 862, 37 и 11. Framingham по тем же 11 комплексам даёт 522.012 и IQR 55.532 при count 11. Это наблюдение записано в `observations_not_adopted.json`. Строка сравнения не переписывалась: в коде ECGDeli последний RR копируется на последний комплекс, и в реконструкции оставлен этот вариант.

## Coverage

Из 432 колонок, которые на шаге 6 были `MISSING`, потому что не было таблицы комплексов:

- 216 интервальных колонок по отведениям теперь имеют число. 192 из них совпали точно. 24 — обмен `aVF`/`aVL`.
- 180 амплитуд и 36 кодов `P_Morph` по-прежнему невосстановимы из одних точек.

Дополнительно 18 Global-колонок интервалов, которые на шаге 6 были `NOT_REPRODUCIBLE` из-за спора max и второй границы, совпали точно с правилом второй границы.

Итого точно совпало 210 из 531, это 39.5%. Покрытие числом — 240 из 531.

## Unknowns

- фильтр и baseline матрицы, из которой ECGDeli читал амплитуды;
- нумерация отсчёта, нулевая или первая, для чтения амплитуды;
- почему файлы `aVF` и `aVL` дают колонки друг друга;
- почему опубликованные RR и Framingham совпадают с 11 интервалами, а строка исходника повторяет последний интервал;
- алгоритм процентиля за пределами тех рядов, которые уже совпали;
- реализация `QT_IntCorr`, `ST_Elev`, `P_Morph` и `HA__Global`.

## Conclusion

Опубликованных fiducial points достаточно, чтобы восстановить интервальную часть таблицы записи 513, включая Global-интервалы по правилу второй крайней границы. Их недостаточно для полной таблицы PTB-XL+ ECGDeli.

Сеть не вызывалась: восстановлены не все 531 колонки. `RAW_TO_531_STATUS` остаётся `NOT_PROVEN`. Production-код не менялся.
