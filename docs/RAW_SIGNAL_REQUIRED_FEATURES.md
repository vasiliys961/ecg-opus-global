# Признаки, которым нужна амплитуда сигнала

Эти колонки не восстанавливаются из опубликованных fiducial points. В файлах `.atr` есть номер сэмпла пика и нет значения в милливольтах.

Семейства: `P_Amp`, `Q_Amp`, `R_Amp`, `S_Amp`, `T_Amp`. У каждого 12 отведений и три статистики, всего 180 колонок.

## Что говорит ECGDeli 1.1

`ExtractAmplitudeFeaturesFromFPT` возвращает сэмпл сигнала в точке fiducial: P peak, Q peak, R peak, S peak, T peak. Функция не вычитает baseline и не переводит ADC в милливольты.

Пример `Annotate_ExampleECG.m` передаёт в эту функцию `ecg_filtered_isoline`, то есть сигнал после фильтра и коррекции изолинии. Сам пример — не прогон PTB-XL+.

## Чего не хватает для числа в таблице

| Вопрос | Состояние |
| --- | --- |
| Сырого PTB-XL 500 Гц и 100 Гц достаточно как файла? | Файлы записи 00513 есть. Это ещё не матрица, которую читает функция. |
| Нужен ли фильтр? | В примере перед аннотацией стоят highpass 1 Гц, lowpass 40 Гц и notch 50 Гц. Какие аргументы были у авторов PTB-XL+, неизвестно. |
| Нужна ли изолиния? | Пример передаёт сигнал после `Isoline_Correction`. Делали ли так авторы таблицы, неизвестно. |
| Нужна ли частота дискретизации? | Индекс сэмпла берётся из fiducial, где написано `time resolution: 500`. Для амплитуды важнее, какой сигнал стоит под этим индексом. |
| База индекса 0 или 1? | Для разности интервалов база сокращается. Для амплитуды сдвиг на один сэмпл меняет значение. База не зафиксирована. |
| Перевод ADC в мВ? | Заголовок WFDB задаёт gain 1000 ADC/mV и baseline 0. Применялось ли это до ECGDeli, неизвестно. Функция амплитуд сама перевод не делает. |

Поэтому формула «какой сэмпл брать» известна, а численное совпадение с опубликованными `P_Amp` / `Q_Amp` / `R_Amp` / `S_Amp` / `T_Amp` из имеющихся артефактов не доказано. Сырой ADC на место авторской матрицы не подставлялся.

Агрегация медианой, IQR и count для этих семейств не выполнялась: без значения сэмпла агрегат не из чего считать.
