# Page

`index.html` is the desktop page. `phone.html` is the phone page. `i18n.js` applies the language cookie. `uvicorn backend.app:app` serves all three. There is no separate frontend build.

The full description is in the repository `README.md`.

---

# Страница

`index.html` — страница компьютера. `phone.html` — страница телефона. `i18n.js` применяет cookie языка. Все три файла отдаёт `uvicorn backend.app:app`. Отдельной сборки фронтенда нет.

Полное описание — в `README.md` репозитория.
