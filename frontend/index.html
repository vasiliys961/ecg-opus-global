ECG Opus

Decision support, not a diagnosis.

Patient

The name stays on this computer and is not sent into the reading.

Why

The phone photographs a sheet or opens a file where there is no computer. The card and the file intake stay here. A reading on the phone does not arrive by itself.

How to link

  1. The phone and this computer are on the same Wi-Fi.
  2. Point the phone camera at the code under the card fields.
  3. Review on the phone scores the recording on the phone and does not send it.
  4. Send to computer is a separate press. A file lands in File, a clip in Strip video. Press Review here yourself.

The name reaches this computer only through Send. It is not sent into the model.

ECG

Choose a file and press Review. If the format does not open, the reason appears under the button.

A clip along the strip is a separate button: frames of one recording are taken from the video.

How to use it

  1. Press File and choose a recording from the machine, or a picture.
  2. Press Review.
  3. If the file has no sampling rate, type it in the field beside File. CSV and MAT need this when the rate is not inside the file. Usual values are 500, 250, or 1000 Hz. A paper speed of 25 mm/s is not the sampling rate.
  4. A tracing of about 10 seconds goes to the calculation. A PDF, a photo, or a sheet goes to the picture and text reading.
  5. If a format does not open, the reason is written under Review.

Files that open

CSV

A lead table. BTL, Schiller, and GE programs often export this when CSV is available. The first row needs the lead names. If the file has only I, II, and V1–V6, the other four leads are derived. Checked on a PTB-XL recording, including that short set.

EDF

Holter recorders and some electrocardiographs, including Contec after conversion to EDF. Checked on a Contec ECG90A recording: the chest leads in that file were a flat line because they were not attached.

WFDB

A .hea and .dat pair in one zip, format 16. This is the PhysioNet exchange form, not a button on the machine. Checked on PTB-XL.

MAT

MATLAB 5, one matrix of 12 leads. PhysioNet Challenge sets are published this way. Checked on recording HR00001. MATLAB 7.3 is not read.

XML

HL7 aECG, used in clinical studies, and Philips PageWriter. Both were checked: a rhythm of about 10 seconds reaches the calculation. XML without samples goes to the text reading.

SCP-ECG

The standard of many European machines, including Schiller, when the file is uncompressed or uses the standard Huffman table. Two such files were checked and the calculation ran.

DICOM

A waveform from PACS and from machines that write a DICOM waveform: Philips, GE. One waveform file was checked. If the DICOM object is a picture rather than a waveform, it goes to the picture reading.

Archive

A zip with one file from the list above opens as that file. Checked on a CSV inside a zip. A WFDB pair in a zip is described above. A zip inside a zip is not taken.

PDF and photos

PDF, PNG, JPEG, GIF, WEBP. A printout or a photograph from any machine, including when its own waveform file is not read. A phone picture in HEIC or HEIF is converted to JPEG and goes to the picture reading.

Russian machines

Neurosoft Poly-Spectrum-SM exports a Holter recording as WFDB. That file is accepted when it is a .hea and .dat pair in one zip, format 16. A full day is longer than 10 seconds, so the whole recording is not scored.

Altonika Alton-106 sends the recording to the Kardis program. Axion EK1T-1/3-07 writes to a memory card and to a computer program. The maker does not name those file formats, and they were not checked here. If the machine prints a sheet, PDF or a photo works.

What is not accepted

  • ZQECG, ZQ machines. There is no public layout.
  • Contec’s own file with the extension .ECG. Their CSV with empty cells written as None is not read either. A PDF or EDF from that machine can be loaded separately.
  • Healforce, including Prince 180D. The file is recognized, but the recordings that were checked are 3 leads and shorter than a second. The calculation expects about 10 seconds and 12 leads.
  • SCP-ECG with its own Huffman table, with bimodal compression, or with reference-beat subtraction.
  • XML from GE MUSE, Mindray, and Mortara. Those XML kinds are not turned into a tracing.
  • A lone .hea or .dat file without its pair in a zip.
